# Week 1: Web Foundations Portfolio

Welcome to my Week 1 portfolio for the **IYF WECAN Academy Season 12**. This project demonstrates my understanding of HTML, CSS, semantic HTML, accessibility and GitHub Pages.

[Visit My Website](https://taurajames.github.io/Iyf-s12-week-01-taurajames/)

## Pages

- **Home:** Introduction to my portfolio.
- **About:** Information about me and my learning journey.
- **Projects:** My projects and practice work.
- **Contact:** A contact form with required fields.
- **Semantic HTML:** Demonstration of semantic HTML elements.
- **Daily Challenges:** My daily coding practice.

## Technologies Used

- HTML
- CSS3
- Git and GitHub
- GitHub Pages

## What I Learned

- How to structure web pages using HTML.
- How to create navigation between multiple pages.
- How to use semantic HTML elements.
- How to create forms with labels and required fields.
- How to publish a website using GitHub Pages.
- How to track changes using Git and GitHub.

## Challenges Faced

- Organizing files and folders correctly.
- Making sure navigation links work across pages.
- Correcting filenames to match assignment requirements.
- Testing my website and checking accessibility.
